# Data Directory README

This directory is the local data workspace for Open Road Risk. It contains raw
source downloads, cleaned/intermediate parquets, model artefacts, public web
exports, and small provenance records.

Most of `data/` is intentionally not stored in git. A new developer should treat
this file as a map of what is expected locally, what is generated by the
pipeline, and which acquisition steps are documented versus still manual.

This README only documents acquisition routes that are already present in repo
code, docs, provenance, or existing scripts. Where the route is not fully
documented, it says so plainly.

## What Is Not Stored In Git

`.gitignore` excludes the large data directories and all parquet files:

- `data/raw/**`
- `data/processed/**`
- `data/features/**`
- `data/models/**`
- `data/outputs/**`
- `data/external/**`
- `*.parquet`, `*.pkl`, `*.joblib`, logs, and generated reports

Small provenance JSON files under `data/provenance/` are intentionally allowed
in git. They are the durable audit trail for data-generation steps.

contract.

## Acquisition Notes By Source

### Documented Automated Acquisition

- **GB boundary**: `scripts/download_gb_boundary.py` downloads ONS Countries
  December 2023 Boundaries UK BGC, keeps England/Scotland/Wales, dissolves to
  one GB feature, and writes `data/raw/boundaries/gb_boundary.gpkg`.
- **WebTRIS**: `src/road_risk/ingest/ingest_webtris.py` uses the configured
  WebTRIS API base URL from `config/settings.yaml`, caches the site list and
  per-site-year pulls under `data/raw/webtris/`, and writes processed outputs.

### Documented Manual Download

These sources have documented source pages or expected files, but the repo does
not automate the download:

- **STATS19**: expected file names and source page are in
  `src/road_risk/ingest/ingest_stats19.py`.
- **AADF**: source page and expected zip are in `quarto/data-sources/aadf.qmd`
  and `src/road_risk/ingest/ingest_aadf.py`.
- **OS Open Roads**: source page, file name, and role are in
  `quarto/data-sources/openroads.qmd`.
- **OS Terrain 50**: source page and ASCII Grid requirement are in
  `quarto/data-sources/terrain.qmd`.
- **Network Model GDB**: source page and local GDB path are in
  `quarto/data-sources/network-model-gdb.qmd`.
- **OSM**: `README.md` and `CODE_README.md` document a full-GB Geofabrik PBF
  command and `osmium` conversion. The current local folder also contains many
  regional extracts; that regional acquisition history is not fully documented.

### Manual Or Not Fully Documented Yet

These sources have local paths and provenance, but not a complete acquisition
recipe in the repo:

- England/Wales OA boundary, Scotland OA boundary, Scotland Data Zone boundary,
  and Wales LSOA boundary.
- OA population CSVs for England/Wales and Scotland.
- GB deprivation raw files beyond the English IoD source URL recorded in
  `imd_provenance.json`.
- England/Wales and Scotland rural/urban classification files.
- MRDB 2024.
- DVSA/test-route material.

For these, use the expected local paths and provenance JSONs as the current
truth, and add acquisition notes when the manual process is reconstructed.

## Generated And Intermediate Outputs

The pipeline convention is:

1. Raw inputs live under `data/raw/`.
2. Cleaned source-level outputs live under `data/processed/`.
3. Model-ready link/link-year features live under `data/features/`.
4. Models, predictions, and diagnostic model outputs live under `data/models/`.
5. Public/static extracts live under `data/outputs/`.
6. Small audit records live under `data/provenance/`.

The most important generated files for a local run are:

- `data/processed/shapefiles/openroads.parquet`
- `data/processed/stats19/collision_clean.parquet`
- `data/processed/stats19/snapped_weighted.parquet`
- `data/processed/aadf/aadf_clean.parquet`
- `data/processed/webtris/webtris_clean.parquet`
- `data/processed/context/oa_population_density_gb.parquet`

## Rebuilding Outputs

Use the detailed order in `CODE_README.md` as the current run-order reference.
The high-level order is:

```bash
python scripts/download_gb_boundary.py
python src/road_risk/ingest/ingest_stats19.py
python src/road_risk/ingest/ingest_aadf.py
python src/road_risk/ingest/ingest_webtris.py
python src/road_risk/ingest/ingest_openroads.py
python src/road_risk/clean_join/clean.py
python src/road_risk/clean_join/snap.py
python src/road_risk/clean_join/join.py
python src/road_risk/features/network.py --osm
python -m road_risk.model --stage traffic
python -m road_risk.model --stage profile
python -m road_risk.model --stage collision
```

Optional or later-stage builders documented in code/docs include:

```bash
python src/road_risk/features/road_curvature.py
python src/road_risk/features/road_terrain.py
python src/road_risk/features/population.py
python src/road_risk/features/deprivation.py
python src/road_risk/features/rural_urban.py
python src/road_risk/outputs/top_risk_segments.py
python src/road_risk/outputs/top_risk_web.py
python scripts/build_context_web.py
```

Do not rerun the full pipeline casually. The current full-GB build is large,
slow, and some acquisition steps are still manual.

## Known Gaps

- Manual acquisition steps for population, RUC, several boundary layers,
  deprivation files, MRDB, and test-route material still need better notes.
- Some provenance files describe an older 2.17M-link build while the current
  validated GB output is 3.94M links. Treat provenance as an audit trail for the
  run that produced it, not as always-current global metadata.
- MRDB is present locally but appears orphaned; see `todo/mrdb_ingest.md`.
- `quarto/_site/` and `quarto/data/outputs/` contain generated site artefacts.
  Do not hand-edit them.
- `PROJECT.md` was not present when this README was written; project-level data
  notes were taken from `README.md`, `CODE_README.md`, `docs/`, `reports/`,
  `quarto/data-sources/`, scripts, config, provenance, and todo files.

## Safety Notes

- Never commit raw data, parquet files, GeoJSON outputs, model files, logs, or
  rendered bulk artefacts unless a task explicitly asks for it.
- Check `.gitignore` before adding anything under `data/`.
- Respect upstream licences and attribution requirements. Existing docs identify
  Open Government Licence usage for OS Open Roads and OS Terrain 50, DfT/public
  sector sources for STATS19/AADF, National Highways for WebTRIS and Network
  Model GDB, and OSM/ODbL implications for OSM-derived attributes.
- Prefer regenerating intermediate files from source data over hand-editing
  generated parquet/GeoJSON files.
- When a manual download is reconstructed, update this README and, where useful,
  add a small provenance record under `data/provenance/`.
